# Tan Video Cutter

Editor de video para Windows orientado a agilizar la edición de videos hablados.

## Objetivo de la primera versión

- Cargar videos MP4
- Detectar y reducir silencios y pausas largas
- Transcribir audio localmente
- Detectar muletillas configurables
- Detectar repeticiones simples
- Revisar los cortes antes de aplicar cambios
- Exportar MP4 sin marca de agua
- Priorizar procesamiento local y herramientas gratuitas

## Stack previsto

- Python
- FFmpeg
- faster-whisper / Whisper local
- PySide6 para la interfaz de escritorio

## Estado

Proyecto recién iniciado. La primera meta es crear un MVP funcional para Windows.
